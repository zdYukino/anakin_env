# Telemetry workstation and synchronized analysis

## 目标

实现高信息密度、可配置的航天风格遥测工作站与实时分析体验。

## 前置与边界

先完成 gateway 与 robot 的数据/模型契约，按父计划串行集成。

继承[父PRD](../11-03-aerospace-telemetry/prd.md)的Q1–Q8和R1–R10，全部改动限制在ui/。

## 范围

所有导航视图、顶部状态、主动DEMO、连接与字段选择、12通道曲线、有界buffer、同步检查器/模型、时间控制、面板重排/调宽/折叠/最大化/保存恢复、精度设置。

## 验收

- [ ] 默认中央左小模型右主数据区；1366×768各主要交互可用，英文UI且读数对齐。
- [ ] 真实源错误不回退DEMO；DEMO主动选择且始终标识；切源无旧样本污染。
- [ ] 12通道曲线可加/移/隐藏、游标/范围同步；60秒buffer有界；约30FPS独立绘图，尖峰保持。
- [ ] 面板与导航/检查器交互、布局保存恢复/重置生效；暂停继续采集，历史与LIVE清晰。
