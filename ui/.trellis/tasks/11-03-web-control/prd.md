# 网页控制与自动仲裁

用户已批准设计及直接实施（2026-11-03）。

将三种来源改为 Unitree 遥控、SDL Joy、网页；完全移除终端键盘控制和 TTY 依赖。普通输入根据实际操作仲裁，同一控制周期冲突优先级为 Unitree > Joy > 网页；所有已启用来源的急停均有效。中立设备心跳不会夺取控制。

连接真实 ROS 数据源后，右上方提供网页控制激活/关闭按钮。激活后总览右侧 02 运动学窗口替换为状态指令；候选动作来自 ENV 已加载 YAML，可用性由实际状态机及入口守卫决定，不可流转按钮为灰色。可打开独立、可拖动的悬浮虚拟 Joy，复用实体控制器映射。

验收：多来源冲突、急停、失联、重连旧按钮、网页租约和乱序输入均有离线测试；网关只允许明确的控制协议，不提供任意 ROS 写接口；浏览器断开/隐藏/失焦归零或释放，失联不自动重新激活；保持现有遥测和控制器显示。运行 C++ 离线检查、网关测试、前端类型/交互/生产构建，尽可能使用浏览器验证。不得触发真实机器人动作。
